Connect to GitHub

This lets the control center save straight to your GitHub site, so every lab computer updates by itself. You only do this once per teacher computer.

You'll type this password to open the control center on this computer. Pick something students won't guess. To change it later, type a new one here and press Connect again.

How do I get an access token?
  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens, then click Generate new token.
  2. Name it something like Lab dashboard and pick an expiration (up to a year).
  3. Under Repository access, choose Only select repositories and pick this site's repository.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above.

The token can only change this one repository. If it ever gets out, delete it on GitHub and make a new one.
